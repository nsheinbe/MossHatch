The brief says to cite the URL and the date for anything that changes over time; the plan itself cites dossier shorthand, so this table is the bridge. All pages were accessed on 2026-09-29 unless a row says otherwise. A page that could not be read on that day is labelled "unreachable" in the Value column, and the fact then comes from another source named in the row (see `docs/research/README.md` for the access limits). "(secondary)" marks a fact that rests on a news site, aggregator or registrar page rather than the authority; "(unverified)" marks a fact a verifier could not confirm from a primary source. Prices are USD per year and excl. tax unless a row says otherwise. Every URL below appears in the cited dossier (or, for library versions, is the npm registry URL of a package named in `tech-npm-versions.md`); the `Dossier` column names the file without the `.md` suffix.
